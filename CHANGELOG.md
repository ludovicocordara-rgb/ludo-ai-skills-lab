# Changelog

## 0.1.0, 29 September 2026

First release for the AI Skills Lab, week 1.

- `ludo` plugin: 33 skills across start-here, research, school, career, finance, making things and shipping code.
- 4 agents: researcher, checker, tutor, fixer. All on Sonnet.
- Working scripts: resume builder (Word and PDF), live DCF and comps workbooks, project packer with secret redaction, usage meter status bar.
- Templates: CLAUDE.md, plan.md, job tracker, study question bank, memory files, slide deck, citation reference.
- `ludo-tools` and `ludo-tools-windows` plugins: a private Chrome browser and live coding docs, preconfigured for students.
- One-line installers for Mac and Windows.
